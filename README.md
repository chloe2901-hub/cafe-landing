# cafe-landing

가상의 카페 **모닝브루**의 간단한 랜딩 페이지예요. HTML과 CSS만으로 만든 정적 웹페이지로, 별도의 빌드 과정 없이 바로 열어볼 수 있어요.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 대표 메뉴, 카페 소개, 오시는 길) |
| `style.css` | 스타일시트 (반응형 카드 레이아웃) |

## 실행 방법

`index.html` 파일을 브라우저로 열면 돼요.

## 참고

- 카페 이름, 메뉴, 가격, 주소, 전화번호는 모두 예시 내용이에요.
